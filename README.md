# LLM and Agentic Engineering Wiki

A repository for research findings on LLMs, agentic engineering tools, and the practices used to build, evaluate, and operate agent systems.

Start with the [wiki index](INDEX.md). Humans and LLM agents share the same Markdown pages, source references, and navigation.

## What belongs here

- Tool evaluations, capability notes, and comparisons.
- Engineering practices for prompting, context management, tool use, orchestration, testing, and evaluation.
- Reproducible experiments and observations from real work.
- Findings with supporting evidence, limitations, and unanswered questions.

## Contributing

1. Read [AGENTS.md](AGENTS.md) and check the relevant section for existing research.
2. Create or update a focused page. Use the [research finding template](templates/research-finding.md) for a new finding.
3. Record evidence, sources, dates, and relevant versions. Separate observation from interpretation.
4. Link the page from its section index and connect it to related research.
5. Check that local links resolve and that conclusions match the available evidence.

The wiki starts with a structure for research. No tool evaluations or experimental results have been recorded yet.
