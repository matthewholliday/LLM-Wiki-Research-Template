### VS Code 1.144 Unleashes Copilot Fusion, AI Image Generation and Computer Use

- By [David Ramel](https://visualstudiomagazine.com/forms/emailtoauthor.aspx?AuthorItem={53762E17-6187-46B4-8C04-9DFA282EBB67}&ArticleItem={B97D0404-11C2-4FF1-9F0A-502ABB107A05})
- 10/28/2026

Microsoft has released Visual Studio Code 1.144, packing its latest AI-focused editor update with Copilot Fusion multi-model orchestration, AI image generation, experimental desktop computer control and expanded cloud agent automation.

The [October 28 release notes](https://code.visualstudio.com/updates/v1_144) emphasize keeping agent sessions running across environments, choosing models for different tasks and giving developers more control over automated code changes.

"This release helps you keep agent work moving across environments, find the right models for each task, and stay in control of changes and tool calls," Microsoft said.

The release coincides with GitHub Universe and consolidates several previously introduced capabilities while adding new functionality across models, agent management, security and customization.

**Copilot Fusion Orchestrates Multiple Models**

One of the biggest changes is the general availability of GitHub Copilot Fusion, which combines Project HydraFusion's multi-model orchestration with Copilot's task-aware model selection.

Instead of manually choosing a model, developers can let Fusion select models, reasoning effort and execution patterns based on the task. A simple request might use one model, while a more complex task could involve separate models generating, reviewing and critiquing a solution.

Fusion provides Standard, High and Max effort levels. High and Max are available on Copilot Pro+, Max, Business and Enterprise plans.

Users are billed for each model Fusion invokes at its standard rate. Microsoft said paid Copilot plans receive a 30% discount on Fusion usage through November 30, 2026.

The update also expands model comparisons, sometimes called Agent Bake-Off, allowing developers to run the same prompt against multiple models and compare results. Comparisons now work without an open project or an existing Git commit, although they are not supported in Dev Containers.

[![VS Code Compare Models picker with options for selecting AI models and configuring a judge.](https://visualstudiomagazine.com/articles/2026/10/28/~/media/ECG/visualstudiomagazine/Images/2026/10/compare_models_picker_s.ashx)](https://visualstudiomagazine.com/articles/2026/10/28/~/media/ECG/visualstudiomagazine/Images/2026/10/compare_models_picker.ashx)**\[Click on image for larger view.\]** Compare Models Picker _(source: Microsoft)._

**Image Generation and Desktop Computer Use**

VS Code 1.144 introduces preview support for generating and editing images directly in Copilot Chat using GPT Image 2.5 Flare.

Developers can request website graphics, icons, backgrounds and wireframes, or provide existing images for modification. Image generation consumes AI credits beyond those used by the conversation model, and an optional setting adds a visible AI-generated watermark.

Another addition is experimental Computer Use, which lets Copilot agents interact with desktop applications on Windows and macOS. The capability works with locally running Copilot harness sessions and requires user authorization before activation.

Developers can enable the feature with the /computer on command and disable it with /computer off.

**Cloud Sessions, Automations and Agent Controls**

The update also expands support for agents running independently of a developer's local machine.

Cloud sessions execute on GitHub infrastructure and remain accessible from VS Code, GitHub.com and GitHub Mobile. They require a paid Copilot plan and remain subject to organizational policies.

New cloud automations, currently in preview, let developers schedule agent tasks or trigger them through repository events such as issue assignments and pull request activity. Automations can be created and managed directly from the Agents window.

Microsoft also published version 1.0 of the Agent Host Protocol, an open protocol for communicating with agent sessions across local and remote environments.

For security, assisted permissions are now generally available. The feature uses an AI-based risk assessment to approve lower-risk tool calls automatically while requiring explicit approval for higher-risk or uncertain operations. Folder isolation is required, and administrators can restrict its use.

An experimental working-set feature also lets developers review Copilot's file edits and selectively keep or undo changes from the editor.

**Agent Marketplace, Connectors and Shared Memory**

VS Code 1.144 expands its agent customization experience with a marketplace-style Browse interface for discovering plugins, skills and other tools.

Copilot connectors, available in preview, provide access to external services through GitHub-managed Model Context Protocol (MCP) servers. Supported integrations include services such as Slack, Notion and Microsoft Learn, with additional offerings available through the connector catalog.

[![VS Code Copilot Connectors catalog showing available external services and integrations.](https://visualstudiomagazine.com/articles/2026/10/28/~/media/ECG/visualstudiomagazine/Images/2026/10/copilot_connectors_s.ashx)](https://visualstudiomagazine.com/articles/2026/10/28/~/media/ECG/visualstudiomagazine/Images/2026/10/copilot_connectors.ashx)**\[Click on image for larger view.\]** Copilot Connectors Catalog _(source: Microsoft)._

The release also adds Copilot Memory support to Copilot harness sessions. Agents can recall repository information and user preferences across sessions, with memories governed by GitHub settings and organizational policies.

Other improvements include more flexible nested sessions, a consolidated Remote Environments dialog, expanded Voice Mode support, enhanced issue reporting and improved editing assistance for custom agent configuration files.

Visual Studio Code 1.144 is available now for Windows, macOS and Linux.
