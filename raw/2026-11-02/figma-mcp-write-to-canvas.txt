Who can use this feature

- Professional, Education, Organization, and Enterprise [plans](https://help.figma.com/hc/en-us/articles/360040328273)
- [Figma Design](https://help.figma.com/hc/en-us/articles/15297425105303), [FigJam](https://help.figma.com/hc/en-us/articles/15300412458647), and Figma Slides
- Requires edit access to the file
- Requires a [supported MCP client](https://developers.figma.com/docs/figma-mcp-server/#h_01K25F7RBRZKCATVJHNXCS6KXW) connected to the remote Figma MCP server

Writing to the canvas is currently in beta and free to use during the beta period. It will eventually become a usage-based paid feature.

With the Figma MCP server, you can prompt your agent to create and edit content directly in your Figma files. Instead of describing a layout in chat and rebuilding it by hand, your agent builds real Figma content: frames, components, variants, variables, and auto layout.

This works especially well with design systems. Your agent can build with the components, variables, and layout rules your team already uses, instead of drawing shapes that only look right. The result is standard, editable Figma content that's easy to review, refine, and build on, with your design system as the source of truth from canvas to code.

Writing to the canvas is different from [sending UI to Figma](https://developers.figma.com/docs/figma-mcp-server/code-to-canvas/). Sending UI to Figma captures a running app as flat layers, without a connection to your libraries. Writing to the canvas builds with your existing components and variables. You can use them together: capture your latest UI, then have your agent refine it with your design system.

For an overview, read [The Figma canvas is now open to agents](https://www.figma.com/blog/the-figma-canvas-is-now-open-to-agents/) on the Shortcut blog.

## How it works [​](https://developers.figma.com/docs/figma-mcp-server/write-to-canvas/\#how-it-works "Direct link to How it works")

Your agent writes to the canvas with the [`use_figma`](https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/#use_figma) tool. The tool lets your agent run code in your Figma file through the [Figma Plugin API](https://developers.figma.com/docs/plugins/), so it can create and update real design structure rather than a screenshot or static export.

tip

Install [Figma's skills](https://help.figma.com/hc/en-us/articles/39166810751895) for your client. The `figma-use` skill helps your agent use `use_figma` reliably and follow the right workflow. Depending on your client, your agent may load it automatically before writing to a file.

Your agent can also read and write **Figma Specs** with the `figma-spec` skill. Share requirements and project context with your agent before it builds, then have it capture decisions and discoveries back in the spec as it works. Figma Specs is in open beta.

## Write to the canvas [​](https://developers.figma.com/docs/figma-mcp-server/write-to-canvas/\#get-started "Direct link to Write to the canvas")

1. [Set up the remote Figma MCP server](https://developers.figma.com/docs/figma-mcp-server/remote-server-installation/) for your client.

2. Open the Figma Design file you want to work in and copy a link:


   - To work in the whole file, copy the URL from your browser's address bar.
   - To work on a specific layer, right-click it and select **Copy link to selection**.

The remote server uses links to know which file or layer to work with.

3. Paste the link into a prompt that tells your agent what to do. For example:


   - "Using this Figma file: <Figma file URL>, create a new page and build a settings screen with auto layout using our existing components."
   - "Using this selection: <link to selection>, convert these raw values to variables and update the surrounding components to use them."
   - "Using this Figma file: <Figma file URL>, add a new empty state that matches the existing design system."

Your agent looks at the file to learn its structure and conventions, then makes the changes.

4. Open the file in Figma to review the result. Then keep prompting your agent to refine it or keep building.


caution

Because this feature is in beta, test on a duplicate of your library or a draft file before changing production files, and keep a backup copy.

## Tips for better results [​](https://developers.figma.com/docs/figma-mcp-server/write-to-canvas/\#tips "Direct link to Tips for better results")

- **Include a link.** Put the file URL or a link to your selection in your prompt so your agent knows exactly where to work.
- **Keep going in the same conversation.** After your first prompt, your agent usually assumes you want to keep working in the same file. For example, after "Using this file: <Figma file URL>, create a profile settings screen," you can follow up with "Add an empty state below that" or "Now convert the color values in this section to variables."
- **Make large changes in steps.** Your agent works best when it reviews the file first, then creates or updates variables, components, and layouts in smaller steps, checking its work as it goes.
- **Name what to use.** When working with a design system, mention the libraries, components, variables, or modes you want your agent to use. You'll get the best results when your agent builds with what already exists in the file.

## Current limitations [​](https://developers.figma.com/docs/figma-mcp-server/write-to-canvas/\#limitations "Direct link to Current limitations")

- Each tool call can return up to 20 KB of output.
- `use_figma` can't add new images on its own. Your agent adds images with [`upload_assets`](https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/#upload_assets), and can create new ones with [`generate_image`](https://developers.figma.com/docs/figma-mcp-server/tools-and-prompts/#generate_image). Importing components that contain images or videos, and creating GIFs, aren't supported yet.
- Fonts must be [uploaded to your Figma account](https://help.figma.com/hc/en-us/articles/360039956894-Add-a-font-to-Figma). Fonts that are only installed on your computer aren't available.
- Components must be published manually before Code Connect mappings can be completed.
- Output is beta quality and may need manual review and cleanup.

Writing to the canvas is being improved continuously. If you run into issues, report them using [Fig, our support chatbot](https://help.figma.com/hc/en-us/articles/360041057214-Explore-Figma-s-help-and-support-resources#h_01KBJZP4HEVHZSHXBV6PFQBPH0), or by [emailing support (paid plans)](https://help.figma.com/hc/en-us/articles/360041057214-Explore-Figma-s-help-and-support-resources#h_01KBJZP4JHXDEZM922NWPF3P9D).
